# MOSQUITO Open Beta 2 Test
This repository contains STEP and STL files for the MOSQUITO Open Beta 2 airsoft kit created by HYBRID ARMORY.

The MOSQUITO by HYBRID ARMORY is a 3D printed airsoft kit purposefully designed to be super compact and lightweight, enabling you to be the real menace on the airsoft battlefield. With the source being available, the MOSQUITO can be endlessly adapted to suit your playstyle.
