# MOSQUITO Open Beta Test
This repository contains STEP and STL files for the open beta 1 test of the MOSQUITO airsoft kit created by HYBRID ARMORY.

The MOSQUITO is a modular, 3D-printed airsoft kit designed to take a V3 gearbox and hop-up chamber from a TM-based AK platform and turn them into a pure menacing machine on the airsoft battlefield through being super compact and lightweight with the same firepower as any other airsoft gun. With the source being available, the MOSQUITO can be endlessly adapted to suit your playstyle.
